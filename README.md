Результат каждой команды извлечения на отдельной строке.

### Пример

**Входные данные**


[Задача №3493 на Informatics](https://informatics.msk.ru/mod/statements/view.php?chapterid=3493)

Реализовать собственную минимальную кучу на C++.

* `CLEAR` — удалить все элементы.
* `ADD n` — добавить число.

### Формат входных данных

До конца ввода поступают команды, каждая на отдельной строке. Всего не более 200000 команд.

### Пример

**Входные данные**

```text

ADD 125
ADD 321
EXTRACT

CLEAR
ADD 7
ADD 555
EXTRACT
EXTRACT
EXTRACT
```

**Выходные данные**

```text
125
321
7
555
CANNOT
```

Вывод: стандартный вывод.

[Задача №3492 на Informatics](https://informatics.msk.ru/mod/statements/view.php?chapterid=3492)

Обработать команды `CLEAR`, `ADD n` и `EXTRACT`. Извлекать максимум, при пустой куче выводить `CANNOT`. Использовать heapq.

$$
\max(a_i)=-\min(-a_i).
$$

### Формат выходных данных

Результат каждого EXTRACT на отдельной строке.

### Пример

**Входные данные**

```text
ADD 192168812
ADD 125
ADD 321
EXTRACT
EXTRACT
CLEAR
ADD 7
ADD 555
EXTRACT
EXTRACT
EXTRACT
```

**Выходные данные**

```text
192168812
321
555
7
CANNOT
```

Вывод: стандартный вывод.

[Задача №746 на Informatics](https://informatics.msk.ru/mod/statements/view.php?chapterid=746)

Каждое сложение стоит $5\%$ от его результата. Найти минимальную стоимость суммирования заданных чисел.

Если $s_j$ — промежуточные суммы, то

$$
C=\frac{5}{100}\sum_{j=1}^{N-1}s_j.
$$

### Формат входных данных

В первой строке $2\le N\le10^5$. Во второй — $N$ натуральных чисел, каждое не больше 10000.

### Формат выходных данных

Минимальная стоимость с двумя знаками после десятичной точки.

### Пример

**Входные данные**

```text
4
10 11 12 13
```

**Выходные данные**

```text
4.60
```

## F. Таможня

Ввод: стандартный ввод.

Вывод: стандартный вывод.

[Задача №1755 на Informatics](https://informatics.msk.ru/mod/statements/view.php?chapterid=1755)

Каждый груз прибывает в момент $T_i$ и занимает аппарат на $L_i$ единиц времени. Найти минимальное число аппаратов, чтобы все досмотры начинались сразу.

Аппарат можно использовать в момент окончания предыдущего досмотра:

$$
A=\max_t|\{i:T_i\le t<T_i+L_i\}|.
$$

### Формат входных данных

Количество грузов $0\le N\le50000$, затем $N$ пар $T_i,L_i$, где $1\le T_i,L_i\le10^6$.

### Формат выходных данных

Минимальное количество аппаратов.

### Пример

**Входные данные**

```text
3
3 2
4 2
5 2
```

**Выходные данные**

```text
2
```

## G. Вычислительная ихтиология

Ввод: стандартный ввод.

Вывод: стандартный вывод.

[Задача №3407 на Informatics](https://informatics.msk.ru/mod/statements/view.php?chapterid=3407)

Колония из $f$ рыбок рождает следующую через $\max(1000-f,1)$ секунд. Игорь начинает у первого аквариума и тратит секунду на переход к соседнему. Каждое рождение нужно зарегистрировать, находясь у нужного аквариума. Найти первое рождение, к которому Игорь не успеет.

После события $(t_0,p)$ следующее событие $(t,i)$ достижимо, если

$$
|i-p|\le t-t_0.
$$

### Формат входных данных

Количество аквариумов $2\le n\le50$, затем $n$ начальных численностей $1\le a_i\le2007$.

### Формат выходных данных

Момент первого рождения, которое нельзя зарегистрировать.

### Пример

**Входные данные**

```text
3
996
1
994
```

**Выходные данные**

```text
7
```
