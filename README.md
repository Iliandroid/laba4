## Двоичная пирамида

При нумерации массива с нуля:

$$
parent(i)=\left\lfloor\frac{i-1}{2}\right\rfloor,\quad left(i)=2i+1,\quad right(i)=2i+2.
$$

В минимальной куче родитель не больше детей, в максимальной — не меньше. Высота равна $O(\log n)$.

## 755 · Хипуй!

[Условие](https://informatics.msk.ru/mod/statements/view.php?chapterid=755) · [Код](755.py)

## 754 · Пирамидальная сортировка

[Условие](https://informatics.msk.ru/mod/statements/view.php?chapterid=754) · [Код](754.py)

Отсортировать N ≤ 100000 целых чисел по неубыванию. Строим максимальную кучу снизу вверх за O(N), затем переносим максимум в конец активной части массива и восстанавливаем кучу. Время O(N log N). Сортировка использует O(1) дополнительной памяти; вся программа с вводом — O(N). Готовые сортировки не используются.

## 3492 · Пирамида (максимум)

[Условие](https://informatics.msk.ru/mod/statements/view.php?chapterid=3492) · [Код](3492.py)

Добавление и извлечение — O(log n), CLEAR — O(n); память программы с ответами — O(Q), где Q — число команд.

## 746 · Коммерческий калькулятор

[Условие](https://informatics.msk.ru/mod/statements/view.php?chapterid=746) · [Код](746.py)

Каждое сложение стоит 5% от результата. Требуется минимизировать стоимость суммирования N натуральных чисел и вывести её с двумя знаками после точки. Из минимальной кучи каждый раз извлекаем два наименьших числа, складываем и возвращаем сумму. Это оптимальное объединение: меньшие значения могут участвовать в большем числе сложений. Стоимость считаем целыми центами, исключая ошибки округления. Время O(N log N), память O(N). Пример: 10, 11, 12, 13 → 4.60.

## 1755 · Таможня

[Условие](https://informatics.msk.ru/mod/statements/view.php?chapterid=1755) · [Код](1755.py)

Для каждого груза даны прибытие T и длительность досмотра L. Найти минимум аппаратов для немедленного начала каждого досмотра. Сортируем грузы по прибытию, в минимальной куче храним окончания досмотров. Удаляем все окончания ≤ текущего прибытия, добавляем T + L. Ответ — максимальный размер кучи. Аппарат доступен уже в момент окончания предыдущего досмотра. При N = 0 ответ 0. Время O(N log N), память O(N).

## 3407 · Вычислительная ихтиология

[Условие](https://informatics.msk.ru/mod/statements/view.php?chapterid=3407) · [Код](3407.py)

Колония из f рыбок рождает следующую через max(1000 − f, 1) секунд. После рождения численность возрастает. Игорь начинает у первого аквариума, переход к соседнему занимает секунду. Требуется время первого рождения, которое он не сможет зарегистрировать. Куча хранит ближайшее событие каждого аквариума. Извлекаем самое раннее, проверяем достижимость, обновляем позицию и назначаем следующее рождение. Одновременные события в разных аквариумах правильно приводят к неудаче. Время O((n + E) log n), память O(n), E — число обработанных событий. Не позднее 499500-й секунды все колонии достигают 1000 рыбок, поэтому моделирование конечно.

## Формулы решений

**Максимум через минимальную кучу (№3492):**

$$\max(a_i)=-\min(-a_i).$$

**Стоимость сложений (№746):** если $s_j$ — очередная сумма,

$$C=\frac{5}{100}\sum_{j=1}^{N-1}s_j,\qquad C_{\text{cents}}=5\sum_{j=1}^{N-1}s_j.$$

**Число аппаратов (№1755):**

$$A=\max_t\left|\{i:T_i\le t<T_i+L_i\}\right|.$$

**Достижимость рождения (№3407):** после события в момент $t_0$ у аквариума $p$ событие $(t,i)$ достижимо тогда и только тогда, когда

$$|i-p|\le t-t_0.$$

Следующее рождение после обновления численности:

$$t_{next}=t+\max(1000-f_{new},1).$$
